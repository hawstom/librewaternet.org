What it does

Everything here works today, in a browser, free, with no account.

This list is long and detailed, but incomplete. Use your browser’s find (Ctrl+F, or ⌘F on a Mac) to search for a feature you are interested in. If you only want to know whether the thing is any good, diving in saves time.

Solver 3

Native solver available for steady state (single moment) simulation.
EPANET 2.3.5 solver for extended period simulations. Solver comparison display.
Auto-recalculate option.

Projects and Saving 2

Multiple open project tabs saved in browser or save to "lwn" file format with locking for office network collaboration.
Install for offline use.

Import, Export, and Map or Backdrop 5

EPANET .inp files import and export with data fidelity and detailed accept/ignore report.
Examples from EPANET and others, XY and Lat/Lon, loaded and solved in one click.
World map canvas or your own backdrop with friendly positioning options.
XY to Lat/Lon conversion import wizard.
Place name search and elevations from map DEM w/ preview.

Adding, editing, and displaying assets and results 8

Junction, reservoir, tank, pipe with vertex draw and edit mode, pump, valve, and annotation text.
Customizable multi- node and link labels including prefixes, suffixes, separator, and drop/shed order with auto or manual placement on leaders or aligned with links.
Find, replace, goto elements including complex queries in your language.
Editable, pasteable, spreadsheet-like asset tables: junctions, reservoirs, tanks, pipes, pumps and valves.
Network coloring: three to seven ranges, eight ways of choosing where the breaks fall, and 41 color ramps.
Multi-line annotation text objects with bold, rotation w/ pipe match option, and association to assets.
Independent size settings for text, symbol, and pipes.
HGL profiles with modern path selection and editing.

Extended period simulations 7

Extended-period simulation following patterns for demands, reservoir head, and pump speed.
EPANET-style rule-based controls.
Pump, efficiency, head loss, and tank volume curves, defined once in the Libraries box beside the patterns and rules and stated by reference, so a manufacturer’s curve keeps every point it was published with and a tank fills on its real shape.
EPANET run report.
Color limits constant through a simulation, so a color means the same thing at every step.
Water quality: age, share from a source, chemical decay.
Pump energy cost: Run length, power use, and cost including peak demand charge.

Premium features included for everybody 4

Fire flow failure and collateral (design) failure analysis.
Scenarios: override management and report, scenario comparison report.
Pipe types: one "150 mm PVC" definition that hundreds of pipes point at, so editing the definition edits every pipe that uses it. Detach one pipe when it needs to be the exception.
Fittings: a pipe’s minor loss summed from named fittings and their quantities, seeded from EPANET’s own thirteen-row table and editable, because the real coefficient depends on size and make.

Language, license, and privacy 3

Twenty-seven languages, and every word is evaluated for translation.
Free software under the GNU GPL, source in the open.
No account, no visitor identifier, and nothing counted about you unless you say yes.
