What it does

Everything here works today, in a browser, free, with no account.

This list is long and detailed, but incomplete. Use your browser’s find (Ctrl+F, or ⌘F on a Mac) to search for a feature you are interested in. If you only want to know whether the thing is any good, diving in saves time.

Solver 3

Native solver available for steady state (single moment) simulation.
EPANET 2.3.5 solver for extended period simulations. Solver comparison display.
Auto-recalculate option.

Projects and Saving 2

Multiple open project tabs saved in browser or save to "lwn" file format with locking for office network collaboration.
Install for offline use.

Import, Export, and Map or Backdrop 9

EPANET .inp files import and export with data fidelity and detailed accept/ignore report.
Examples from EPANET and others, XY and Lat/Lon, loaded and solved in one click.
World map canvas or your own backdrop with friendly positioning options.
XY to Lat/Lon conversion import wizard.
Convert a copy of a project to another coordinate system and other units, with a wizard that zooms, scales, and rotates your network onto the map; new projects can start in a real EPSG projection.
Import points, lines, and polygons from GeoJSON, shapefile, and DXF files as Shapes, and import a list of surveyed points as junctions.
Libraries of patterns, curves, controls, rules, pipe types, and fittings, with pipes attached to a library pipe type and fittings list by reference so they stay in sync, and whole libraries copied in from another project file.
Export tables to ODS, XLSX, or CSV by table and scenario with the libraries they refer to, copy any table with its headings, and take a screenshot of the map and copy it into a report. Network export to GeoJSON and DXF, and a workspace file that carries your box layout to another screen.
Place name search and elevations from map DEM w/ preview.

Adding, editing, and displaying assets and results 14

Junction, reservoir, tank, pipe with vertex draw and edit mode, pump, valve, and annotation text.
Junction Pipe Chain tool: specify points along the map to draw junction, pipe, junction until you press Escape, or specify an existing node to continue from it; a junction placed on a pipe offers to split that pipe at the new node.
Draw Shapes (points, lines, and polygons) on the map, kept in a Shapes table; a Shape is annotation and is not part of the network.
Snap to objects: nodes, pipe vertices, points along a pipe, and Shape points all attract the cursor, which makes imported DXF and shapefile Shapes something you can trace a network from.
Customizable multi- node and link labels including prefixes, suffixes, separator, and drop/shed order with auto or manual placement on leaders or aligned with links.
Find, replace, goto elements including complex queries in your language.
Editable, pasteable, spreadsheet-like asset tables: junctions, reservoirs, tanks, pipes, pumps and valves.
Group edit assets three different ways: Find and replace, Select area, and spreadsheet edit Tables.
Network coloring: three to seven ranges, eight ways of choosing where the breaks fall, and 41 color ramps.
Multi-line annotation text objects with bold, rotation w/ pipe match option, and association to assets.
Independent size settings for text, symbol, and pipes.
HGL profiles with modern path selection and editing.
Graphs: time series, profile, contour on the map, frequency distribution, and a flow balance of production against consumption.
Time series graphs at the foot of Properties and as bubbles on the map from an asset’s right-click menu, including tank depth; the bubbles are a Presentation override.

Extended period simulations 7

Extended-period simulation following patterns for demands, reservoir head, and pump speed.
EPANET-style rule-based controls.
Pump, efficiency, head loss, and tank volume curves, defined once in the Libraries box beside the patterns and rules and stated by reference, so a manufacturer’s curve keeps every point it was published with and a tank fills on its real shape.
EPANET run report.
Color limits constant through a simulation, so a color means the same thing at every step.
Water quality: age, share from a source, chemical decay.
Pump energy report: for each pump, the share of the run it operates, efficiency, average and peak power, energy used, and cost including a peak demand charge.

Analyses 2

Fire flow failure and collateral (design) failure analysis.
Criticality, which removes each pipe, pump, and valve in turn and reports the effect, and demand scaling, which finds the largest demand scale the system can carry, both run on a copy of the network.

Scenarios and alternatives 2

Scenarios whose overrides are marked on the map with an amber ring, a Manage overrides list that shows each override beside the value it replaces and clears any of them, a Copy properties command that carries an asset’s overrides, and a comparison report that solves every scenario from a copy and tabulates its overrides, lowest pressure, and highest velocity.
Alternatives that build on one another in an inheritance tree, shared among scenarios, with overrides mergeable upward into the alternative above, each alternative holding overrides in categories such as Presentation (how the map looks, including a saved map view) and Calculation (run time and time step), ready-made scenarios in every new project, and a Basic mode that hides the alternatives until you want them, and many more management features.

Premium features included for everybody 2

Scenarios and alternatives (see Scenarios and alternatives).
Fire flow, criticality, and demand scaling analyses (see Analyses).

Language, license, and privacy 3

Twenty-seven languages, and every word is evaluated for translation.

No account, no visitor identifier, and nothing counted about you unless you say yes.
